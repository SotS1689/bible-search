⛪ BibleSearch — Command Line Quick Reference

Search Operators

ExampleOperatorWhat it does
.κύριος. (AND, default)Find every verse containing this word (any form). Single-term search.
.κύριος θεός. word wordAND: both words must appear in the same verse.
.κύριος !θεός! (NOT)AND-NOT: κύριος present but θεός absent.
'Ἰησοῦς Χριστός' (phrase)Phrase: words must appear in this exact sequence.
/κύριος θεός/ (OR)Either word may appear in the verse.
.κύριος θεός;5;N (proximity)Both words within N verses of each other.
'Ἰησοῦς *2 Χριστός*N (gap)Phrase with up to N intervening words allowed.
(.κύριος).(.θεός)( ) compound ANDAND of two grouped sub-expressions.
(.κύριος)./(.θεός)( )./( ) compound OROR of two grouped sub-expressions.
(.κύριος).!(.θεός)( ).!( ) compound NOTFirst group present, second group absent.

Wildcards

ExampleWildcardWhat it does
.πιστ** (any sequence)Matches any ending: πίστις, πιστεύω, πιστός, etc.
.λόγο?? (single character)Matches exactly one character in that position.
.*@vii*.* with morph codeAny word matching the given morphology code.

Morphology Codes — Greek

Append @code after a lemma: .λόγος@n*  |  Use * as wildcard within codes: .*@viia3s

ExampleCode patternMeaning
.πιστεύω@viia3sv + mood + tense + voice + person + numberVerb, indicative, aorist, active, 3rd singular
.λόγος@nnms*n + case + gender + numberNoun, nominative, masculine, singular
.*@vp*a*vp = participleAny participle in active voice
.*@vn**vn = infinitiveAny infinitive
.*@vi**3p3p = 3rd pluralAny indicative verb, 3rd plural

Mood: i=indicative  d=imperative  s=subjunctive  o=optative  n=infinitive  p=participle
Tense: p=present  f=future  a=aorist  i=imperfect  x=perfect  y=pluperfect
Voice: a=active  m=middle  p=passive  e=middle/passive
Case: n=nom  g=gen  d=dat  a=acc  v=voc    Gender: m=masc  f=fem  n=neut    Number: s=sg  p=pl

Morphology Codes — Hebrew

Hebrew lemmas use Strong's numbers: .1254@vq*  |  Or type Hebrew directly: .ברא@vqp3ms

ExampleCode patternMeaning
.1254@vqp3msRqv + stem + tense + person + gender + number + RqVerb, Qal, perfect, 3ms (Qere)
.430@ncmpa*n + type + gender + number + stateNoun, common, masculine, plural, absolute
.*@vqp*vqp = Qal perfectAny Qal perfect verb
.*@vN**vN = NiphalAny Niphal verb
.*@vh**vh = HiphilAny Hiphil verb

Stem: q=Qal  N=Niphal  p=Piel  P=Pual  h=Hiphil  H=Hophal  d=Hithpael
Tense: p=perfect  i=imperfect  v=wayyiqtol  a=imperative  r=ptcp.act  s=ptcp.pass  e=inf.const  f=inf.abs
State: a=absolute  c=construct  d=determined    Qere/Kethib: Rq=Qere  Rk=Kethib  Rx=both
